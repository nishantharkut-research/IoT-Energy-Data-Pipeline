# Coursework report and presentation assets

Submit [project-report.pdf](project-report.pdf) with the repository link:
https://github.com/nishantharkut-research/IoT-Energy-Data-Pipeline

The report is 16 pages and includes eight captures from the actual saved-results dashboard, two vector diagrams and generated numerical tables. The editable source is `project-report.tex`.

`figures/01-...png` through `08-...png` preserve the full dashboard content for each view. The corresponding `report-...png` files capture focused panels at a readable report size. `overview-desktop.png` includes the sidebar. `browser-checks.json` records the capture checks. Diagram sources are generated by `scripts/build_submission_figures.py`; PDF and SVG versions are retained.

The results are the original completed experiments. Preparing this report and viewer started no new distributed workload. The portable viewer validates committed summaries; original sealed runtime artifacts are required for a full per-artifact audit. See [the handover](../HANDOVER.md) and [submission checks](../results/submission/verification.md).

To rebuild with an active project environment and LaTeX:

```bash
python -m scripts.build_submission_figures
# Optional: recapture from the running dashboard.
python -m scripts.capture_submission_screenshots
latexmk -pdf -cd -interaction=nonstopmode -halt-on-error docs/submission/project-report.tex
```
