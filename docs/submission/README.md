# Coursework report and presentation assets

Submit [project-report.pdf](project-report.pdf) with the repository link:
https://github.com/nishantharkut-research/IoT-Energy-Data-Pipeline

The report includes the problem and Indian utility-review use case, source preparation, architecture, exact processing contracts, completed experiments, interpretation limits, and nine large landscape captures of the actual React dashboard. The editable source is `project-report.tex`.

`figures/dashboard/01-*.png` through `09-*.png` preserve full-page content. The corresponding `report-*.png` files capture the full 1280×900 desktop viewport with navigation and context. `run-inspector-dialog.png` demonstrates a working interaction. `browser-checks.json` records page, interaction, tamper-rejection and responsive checks. The earlier Streamlit captures remain historical assets and are not used by the current report.

Two vector diagrams and numerical tables are generated by `scripts/build_submission_figures.py`; PDF and SVG versions are retained. No peer project's wording or figures are copied.

The results are the original completed experiments. This presentation update starts no distributed workload. The React viewer validates committed summaries; original sealed runtime artifacts are needed for a full per-artifact audit. See [the handover](../HANDOVER.md), [India use case](../india-use-case.md) and [submission checks](../results/submission/verification.md).

To rebuild with an active Python environment, LaTeX and the React dashboard running on port 5173:

```bash
python -m scripts.build_submission_figures
python -m scripts.capture_operator_dashboard
latexmk -pdf -cd -interaction=nonstopmode -halt-on-error docs/submission/project-report.tex
python -m scripts.export_dashboard_evidence
```

The final export refreshes the dashboard's downloadable report copy. It does not change any original experiment evidence.
