**Auditable IoT Energy Data Pipeline**

- Author: Nishant Harkut

Submit [project-report.pdf](project-report.pdf) and the repository link. The editable report is [project-report.tex](project-report.tex).

The 22-page report covers the Indian utility-review use case, source preparation, processing contracts, architecture, completed experiments, results and limitations. It includes two vector diagrams and nine landscape captures from the final desktop dashboard. Full-page screenshots and the run-inspector capture are in `figures/dashboard/`.

The evaluation contains 15 completed runs, including three repetitions each at 100K and 1M records. The final scope excludes 5M runs. The report uses existing measured results; the submission build starts no distributed experiment.

## Rebuild

With the report Python extra, LaTeX and the dashboard running on port 5173:

```bash
python -m scripts.build_submission_figures
python -m scripts.capture_operator_dashboard
latexmk -pdf -cd -interaction=nonstopmode -halt-on-error docs/submission/project-report.tex
python -m scripts.export_dashboard_evidence
npm --prefix dashboard/web run build
```

The export and frontend build refresh the dashboard's report download. The diagrams and numerical tables are generated by `scripts/build_submission_figures.py`. The browser captures show the running application.
